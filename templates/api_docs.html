🤖 Prediction Endpoints

POST /api/predict Single-point demand prediction ▾

Predicts electricity demand in kWh for a given date, hour, temperature, and humidity. Works in demo mode if model is not trained.

Request Body (application/json)
{
  "date": "2025-08-15",   // YYYY-MM-DD (required)
  "hour": 14,          // 0–23 (required)
  "temperature": 32.5,  // °C (optional, default 25)
  "humidity": 55       // 0–100 % (optional, default 60)
}
Response (200 OK)
{
  "success": true,
  "prediction": 6842.17,
  "unit": "kWh",
  "demo_mode": false,
  "input": { "date": "2025-08-15", "hour": 14, "day_of_week": "Friday", ... },
  "model_info": { "name": "Random Forest", "accuracy": "95.3%" }
}
⚡ Try It Live
POST /api/compare Two-scenario comparison ▾

Compares two prediction scenarios and returns both predictions, the difference in kWh and percentage, and which scenario is higher.

Request Body
{
  "scenario_a": { "date": "2025-06-05", "hour": 14, "temperature": 25, "humidity": 60 },
  "scenario_b": { "date": "2025-06-05", "hour": 14, "temperature": 38, "humidity": 30 }
}
Response Fields
{
  "scenario_a": { "prediction": 5720, "input": {...} },
  "scenario_b": { "prediction": 6940, "input": {...} },
  "comparison": {
    "difference_kwh": 1220,
    "difference_percent": 21.3,
    "higher_scenario": "B"
  }
}
POST /api/forecast-multi Multi-step 24/48/72h forecast ▾

Generates hourly predictions for the next 24, 48, or 72 hours with confidence intervals.

Request Body
{
  "date": "2025-06-05",
  "hour": 0,
  "hours": 24,    // 24, 48 or 72
  "temperature": 28,
  "humidity": 65
}
Each Prediction Object
{ "timestamp": "2025-06-05 00:00", "prediction": 4120,
  "lower_bound": 3895, "upper_bound": 4345,
  "is_peak": false, "temperature": 25.1, "humidity": 69.8 }

POST /api/detect-anomalies Statistical anomaly detection on historical data ▾

No request body required. Analyses the data/electricity_demand.csv file using a 7-day rolling window (2σ threshold) to identify demand spikes and drops.

Response Summary Fields
{ "total_anomalies": 42, "critical_count": 3, "high_count": 9,
  "anomalies": [{ "timestamp": "...", "actual_demand": ...,
    "deviation_percent": ..., "severity": "high",
    "cause": "...", "type": "spike" }] }
